# Allen Neuropixels Neural Dynamics

A minimal experiment for predicting neural population dynamics from the Allen Brain Observatory Visual Coding Neuropixels dataset using a hybrid mechanistic (Wilson-Cowan) and machine learning model.

## Quickstart

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run experiment:
   ```bash
   python run_experiment.py
   ```
